# MVP Start Plan

## Goal

Build a safe, inspectable IRIS core before connecting real platform APIs.

## MVP 0

- Accept a normalized comment event.
- Produce a canonical action through Phase01-04.
- Pass through Phase05-13 with minimal contract-safe evaluators.
- Generate a mock response draft before Phase14.
- Naturalize surface text through Phase14.
- Run final output guard through Phase15.
- Hand off to mock TTS and Live2D adapters.
- Optionally commit approved memory records to a local JSON store.
- Expose a local HTTP development server and OBS-style browser overlay state.

## Deferred

- Real YouTube Live API connection
- Real TTS engine
- Real Live2D bridge
- Production OBS overlay beyond the local prototype
- Production memory commit and retrieval
- Relationship depth
- Game perception and game operation

These are deferred so the Phase00 boundary and Phase01-15 contracts can become stable first.
