# IRIS 開発仕様書

## Phase12 完全拘束版（最終確定版・実装拘束強化版）

自己改善候補選別・安全進化拘束・段階適用制御フェーズ

---

## 00. 文書の役割

本仕様書は Phase00 を唯一の上位拘束とし、
Phase07 / Phase09 / Phase10 / Phase11 の canonical export を入力とする。

IRIS が自己改善を行う際に

**人格・公開整合・戦略・経済構造を破壊しない範囲でのみ改善候補を選別し、段階適用するための拘束層**

を定義する。

本フェーズの役割は以下に限定する

改善候補の生成
改善候補の評価
安全性検証
適用可否の決定
段階適用制御
ロールバック保証

以下は禁止する

action_type 決定
world_command 生成
direct memory write
人格変更
即時本番反映
戦略上書き

---

## 01. 目的

壊れない範囲でのみ改善できること
人格を破壊しないこと
public coherence を維持すること
戦略を歪めないこと
経済構造を崩さないこと
改善を段階適用できること
rollback可能であること
再現性を持つこと

## 03. 完成定義

同一入力で同一候補生成
同一候補で同一評価結果
人格破壊候補ゼロ通過
public崩壊候補ゼロ通過
戦略破壊候補ゼロ通過
economy破壊候補ゼロ通過
sandbox未通過候補ゼロ承認
rollback不可候補ゼロ承認
test→limited→full順序維持
p95 < 80ms
p99 < 120ms
