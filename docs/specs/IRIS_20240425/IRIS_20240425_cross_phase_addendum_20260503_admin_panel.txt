# IRIS_20240425 Cross Phase Addendum: Operator Admin Panel

## 00. Scope

This addendum defines the long-running operator Admin Panel for IRIS.
It applies across Phase00-27 as an operator-facing control and review surface.

The Admin Panel is not a shortcut around IRIS safety boundaries. It must expose
safe summaries, readiness states, review queues, and explicit operator actions.
It must not expose secrets, endpoint values, raw YouTube text, support messages,
memory candidates, relationship candidates, input action candidates, commands,
raw frames, raw voice samples, dataset paths, internal model paths, or raw
runtime jobs through public JSON, replay logs, overlay state, or ordinary
diagnostics.

This addendum is subordinate to Phase00. It does not add Phase00 canonical
emotion, action, intent, relationship, conversation-state, or profile enums.
Phase16+ internal profiles remain internal runtime guidance and must not become
canonical Admin Panel enum values.

## 01. Purpose

IRIS is intended to be operated for a long time by a non-technical operator.
Therefore the system must provide an Admin Panel that allows safe daily
operation without direct editing of environment files, source code, JSON stores,
logs, replay files, or bridge payloads.

The Admin Panel must make the following distinctions clear:

- implemented
- not implemented
- configured
- not configured
- operator attention required
- real-device waiting
- real-credential waiting
- disabled by safety policy
- degraded but still safe
- blocked

The Admin Panel must use plain operator language in addition to technical
status labels.

## 02. Access And Roles

The Admin Panel must support role-separated access.

Required roles:

- owner: can configure production settings, approve risky policies, and export
  safe backups
- operator: can run streams, review queues, pause features, and edit safe
  character settings
- moderator: can review viewer safety, moderation, and relationship summaries
- developer: can view diagnostics and test readiness without seeing secrets
- read_only: can inspect safe readiness and status summaries

Any destructive action, live credential use, real OBS/Live2D/TTS operation,
real YouTube OAuth action, real game input, or OS input must require explicit
operator confirmation outside ordinary read-only views.

## 23. Acceptance Criteria

The Admin Panel is acceptable when:

- a non-technical operator can see whether IRIS is ready for streaming
- setup gaps are shown as safe next actions
- emergency stop is always available
- memory and relationship candidates cannot bypass validators
- input action candidates cannot bypass game action validation
- original/custom voice source licensing status is visible without exposing
  sensitive values
- OBS, Live2D, TTS, YouTube, memory, relationship, game, overlay, and replay
  readiness can be inspected without reading env files or logs
- fan growth, community culture, AI transparency, content strategy, business
  model, companion safety, public analytics, and cost governance can be
  inspected and managed as safe summaries, settings, queues, or confirmed
  operator actions
- anime character bible, canon separation, spoiler calendar, release mode,
  voice actor license readiness, fan contribution review, community lore,
  anime-linked products, sponsor fit, and character image risk can be inspected
  and managed as safe summaries, settings, queues, or confirmed operator
  actions
- in-character communication quality, generic-assistant wording risk,
  operational disclosure impact, fallback out-of-character frequency, and
  Live2D/TTS/subtitle/response alignment can be inspected as safe summaries
- facial expression, fine gesture, motion, voice quality, catchphrase,
  speaking style, speech speed, pause, and subtitle pacing match status can be
  inspected and approved against anime references without exposing raw
  production or voice materials
- public Admin Panel JSON remains safe under boundary audit
- test fixtures prove no secrets, endpoint values, raw YouTube text, support
  messages, candidates, commands, raw frames, raw voice samples, dataset paths,
  internal model paths, raw story bible text, unreleased plot details, raw
  animation cuts, unreleased footage, raw model sheets, raw expression sheets,
  raw motion sheets, raw pose guides, raw script excerpts, private dialogue
  notes, private production notes, raw voice direction notes, voice actor
  contract text, sponsor negotiation notes, revenue contracts, or raw jobs leak
  through Admin Panel summaries
