
---

## 10. Goal Aging Engine（最重要）

```json
{
  "goal_age": 0,
  "decay_applied": 0.0
}
```

---

## ルール

```text
選択されたgoalはgoal_ageを加算
```

```text
goal_age > threshold の場合
scoreに減衰を適用
```

---

## 減衰式

```text
adjusted_score = score × decay_factor
```

---

## 推奨値

```text
threshold = 5〜10イベント
decay_factor = 0.7〜0.85
```

---

## 11. Goal Rotation Controller（最重要修正）

👉 **スコアを無視して強制切替**

```json
{
  "rotation_triggered": true,
  "forced_goal": "EXPLORE_NEW"
}
```

---

## 発動条件

```text
同一goalが連続N回選択された場合
```

---

## 推奨値

```text
N = 3〜5回
```

---

## 動作（重要）

```text
rotation発動時

1. 強制goal選択（スコア無視）
2. 次の1回は必ず維持
3. 前goalは一時的に選択禁止
```

---

## 12. Recent Goal Penalty Engine（追加）

```json
{
  "penalized_goals": [],
  "penalty_factor": 0.0
}
```

---

## ルール

```text

```

---

## 計算

```text
penalized_score = score × penalty_factor
```

---

## 推奨値

```text
penalty_factor = 0.5〜0.7
```
