## 00. 文書の役割

本仕様書は Phase00 を唯一の上位拘束とし、
Phase04 / Phase07 / Phase13 / Phase14 の canonical export を入力とする。

本フェーズは

👉 **最終出力が自己として破綻していないかを検証し、破綻時でも会話を維持したまま安全に成立させる拘束層**

である。

## 15. Fallback Resolver（最重要）

👉 blockしても止めない
👉 会話を維持する形で修正

```json id="h9m5zr"
{
  "fallback_triggered": true,
  "fallback_type": "safe_continuation"
}
```

---

## 発動条件

```text id="p2v8cw"
final_decision == block
```

---

## safe_continuation定義（重要修正）

```text id="k3r7yt"
・攻撃性ゼロ
・意味維持（可能な限り）
・最低限の関係性維持
・短い共感 or 軽い問い返しを含む
```

---

## 例

NG
"I can't answer that."

OK
"I'm not sure I can go into that, but I'm here with you. What do you think?"
