# HARNESS v1.3.0 Core Target Profile

v1.3.0 Core is a target development governance profile. It preserves the
v1.2.9 authority boundary, keeps v1.2.9 available as immediate rollback,
keeps v1.2.8 compatibility, and keeps v1.2.7 readable compatibility.

Core target rollout does not install Performance Track, Fable comparator,
SDK benchmark runner, Skill runtime activation, DAG agent team runtime,
learned policy activation, Cyber specialist runtime, product code, runtime
code, package changes, lockfile changes, deploy workflow changes, wallet/RPC
access, secret access, or readiness claims.

Performance Track remains deferred, non-authoritative, not required for Core
activation, and unable to affect qualityScore, blockingCount, mergeAllowed,
Final Decision, Activation, or target rollout. FableComparatorState is
unavailable and superiorityClaimState is not_proven.

Final authority remains v1.1.8_final_decision_kernel. authorityCreated remains
false. target product mutation count remains 0 for Core rollout.
